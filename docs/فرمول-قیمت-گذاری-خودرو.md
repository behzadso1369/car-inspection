# فرمول قیمت‌گذاری خودرو کارکرده

مستند فنی الگوریتم صفحه `/car-price`. منبع کد: `src/lib/car-price/pricing.ts` و `src/app/car-price/page.tsx`.

---

## ایده کلی

قیمت نهایی حاصل ضرب **قیمت پایه** در چهار ضریب مستقل است:

```
قیمت نهایی = قیمت پایه × ضریب سال × ضریب کارکرد × ضریب رنگ × ضریب شاسی
```

سپس این عدد به نزدیک‌ترین **بازه ۱۰۰ میلیون تومانی** گرد می‌شود و به کاربر نمایش داده می‌شود.

هر ضریب بین صفر و یک است؛ یعنی فقط می‌تواند قیمت را کم کند یا ثابت نگه دارد. ضریب بیشتر از ۱ وجود ندارد.

---

## ورودی‌ها

| ورودی | توضیح | منبع |
|---|---|---|
| `basePrice` | قیمت پایه مدل (تومان) | دیتای `car.json` + اصلاح همراه مکانیک |
| `lastYear` | آخرین سال تولید / مدل مرجع در دیتا | فیلد `lastYear` خودرو |
| `year` | سال ساخت خودرو کاربر | ورودی کاربر (۱۳۸۰ تا `lastYear + 1`) |
| `km` | کارکرد به کیلومتر | ورودی کاربر |
| `body` | وضعیت رنگ / بدنه | یکی از ۶ حالت جدول رنگ |
| `chassis` | وضعیت شاسی و اتاق | یکی از ۳ حالت جدول شاسی |

---

## مرحله ۱ — قیمت پایه

قیمت خام از دیتای خودرو (`carPrice`) خوانده می‌شود.

اگر منبع قیمت `hamrah` (همراه مکانیک) باشد، **۴۰۰ میلیون تومان** به آن اضافه می‌شود:

```
اگر source === "hamrah":
    قیمت پایه = قیمت دیتا + ۴۰۰٬۰۰۰٬۰۰۰
وگرنه:
    قیمت پایه = قیمت دیتا
```

این اصلاح فقط روی خودروهای همراه مکانیک اعمال می‌شود و قبل از ورود به فرمول اصلی است.

---

## مرحله ۲ — ضریب سال (`yearFactor`)

سن خودرو نسبت به آخرین سال مدل در دیتا محاسبه می‌شود:

```
سن = max(0, lastYear − year)
کاهش سال = min(سن × 0.02, 0.50)
ضریب سال = 1 − کاهش سال
```

- هر سال کارکرد نسبت به مدل مرجع، **۲٪** از قیمت کم می‌کند.
- سقف کاهش سال **۵۰٪** است (یعنی ضریب سال هیچ‌وقت از `0.50` پایین‌تر نمی‌رود).
- اگر سال واردشده از `lastYear` جدیدتر باشد، سن صفر در نظر گرفته می‌شود و ضریب سال `1` می‌ماند.

| سن (سال) | کاهش | ضریب سال |
|---|---|---|
| ۰ | ۰٪ | ۱٫۰۰ |
| ۱ | ۲٪ | ۰٫۹۸ |
| ۲ | ۴٪ | ۰٫۹۶ |
| ۵ | ۱۰٪ | ۰٫۹۰ |
| ۱۰ | ۲۰٪ | ۰٫۸۰ |
| ۲۵ و بیشتر | ۵۰٪ (سقف) | ۰٫۵۰ |

---

## مرحله ۳ — ضریب کارکرد (`kmFactor`)

```
کاهش کارکرد = min((km / 10_000) × 0.03, 0.30)
ضریب کارکرد = 1 − کاهش کارکرد
```

- هر **۱۰ هزار کیلومتر** کارکرد، **۳٪** از قیمت کم می‌کند.
- سقف کاهش کارکرد **۳۰٪** است (ضریب کارکرد حداقل `0.70`).
- این سقف از حدود **۱۰۰ هزار کیلومتر** به بعد فعال می‌شود:

```
(100_000 / 10_000) × 0.03 = 0.30
```

| کارکرد | کاهش | ضریب کارکرد |
|---|---|---|
| ۰ | ۰٪ | ۱٫۰۰ |
| ۱۰٬۰۰۰ | ۳٪ | ۰٫۹۷ |
| ۵۰٬۰۰۰ | ۱۵٪ | ۰٫۸۵ |
| ۸۰٬۰۰۰ | ۲۴٪ | ۰٫۷۶ |
| ۱۰۰٬۰۰۰ | ۳۰٪ (سقف) | ۰٫۷۰ |
| ۲۰۰٬۰۰۰ | ۳۰٪ (سقف) | ۰٫۷۰ |

---

## مرحله ۴ — ضریب رنگ / بدنه (`bodyFactor`)

| وضعیت رنگ | ضریب |
|---|---|
| بی‌رنگ | ۱٫۰۰ |
| خط و خش جزئی | ۰٫۹۸ |
| صافکاری بدون رنگ | ۰٫۹۴ |
| رنگ یک ناحیه | ۰٫۹۲ |
| رنگ دو ناحیه | ۰٫۸۸ |
| رنگ چند ناحیه | ۰٫۸۲ |

---

## مرحله ۵ — ضریب شاسی (`chassisFactor`)

| وضعیت شاسی | ضریب |
|---|---|
| سالم | ۱٫۰۰ |
| ضربه خورده | ۰٫۷۷ |
| آسیب شدید | ۰٫۶۵ |

شاسی بیشترین وزن را در فرمول دارد. آسیب شدید شاسی به‌تنهایی ۳۵٪ قیمت را کم می‌کند.

---

## مرحله ۶ — قیمت نهایی و بازه

```
قیمت نهایی = round(قیمت پایه × ضریب سال × ضریب کارکرد × ضریب رنگ × ضریب شاسی)
```

بازه نمایشی روی پله‌های **۱۰۰ میلیون تومان** ساخته می‌شود:

```
واحد = ۱۰۰٬۰۰۰٬۰۰۰
حداقل = floor(قیمت نهایی / واحد) × واحد
حداکثر = حداقل + واحد
```

مثال: اگر قیمت محاسبه‌شده `۸۱۶٬۰۰۰٬۰۰۰` باشد، بازه نمایشی **۸۰۰ تا ۹۰۰ میلیون تومان** است.

کاربر در صفحه نتیجه همین بازه را می‌بیند، نه عدد دقیق.

---

## فرمول یک‌خطی

```
سن          = max(0, lastYear − year)
ضریب سال    = 1 − min(سن × 0.02, 0.50)
ضریب کارکرد = 1 − min((km / 10000) × 0.03, 0.30)
ضریب رنگ    = BODY_FACTORS[وضعیت رنگ]
ضریب شاسی   = CHASSIS_FACTORS[وضعیت شاسی]

قیمت نهایی  = round(قیمت پایه × ضریب سال × ضریب کارکرد × ضریب رنگ × ضریب شاسی)

بازه.min    = floor(قیمت نهایی / 1e8) × 1e8
بازه.max    = بازه.min + 1e8
```

## مثال عددی ۱ — خودروی تمیز

| پارامتر | مقدار |
|---|---|
| قیمت پایه (بعد از اصلاح همراه) | ۱٬۰۰۰٬۰۰۰٬۰۰۰ تومان |
| آخرین سال مدل | ۱۴۰۳ |
| سال ساخت | ۱۴۰۱ |
| کارکرد | ۵۰٬۰۰۰ کیلومتر |
| رنگ | بی‌رنگ |
| شاسی | سالم |

محاسبه:

```
سن          = 1403 − 1401 = 2
ضریب سال    = 1 − (2 × 0.02) = 0.96
ضریب کارکرد = 1 − (5 × 0.03) = 0.85
ضریب رنگ    = 1.00
ضریب شاسی   = 1.00

قیمت نهایی  = 1_000_000_000 × 0.96 × 0.85 × 1 × 1
            = 816_000_000 تومان

بازه        = ۸۰۰٬۰۰۰٬۰۰۰ تا ۹۰۰٬۰۰۰٬۰۰۰ تومان
```

## مثال عددی ۲ — بدنه و شاسی آسیب‌دیده + کارکرد بالا

| پارامتر | مقدار |
|---|---|
| قیمت پایه | ۸۰۰٬۰۰۰٬۰۰۰ تومان |
| آخرین سال مدل | ۱۴۰۳ |
| سال ساخت | ۱۳۹۸ |
| کارکرد | ۱۵۰٬۰۰۰ کیلومتر |
| رنگ | رنگ دو ناحیه |
| شاسی | ضربه خورده |

محاسبه:

```
سن          = 5
ضریب سال    = 1 − 0.10 = 0.90
کاهش کارکرد = min(15 × 0.03, 0.30) = 0.30   ← سقف فعال شد
ضریب کارکرد = 0.70
ضریب رنگ    = 0.88
ضریب شاسی   = 0.77

قیمت نهایی  = 800_000_000 × 0.90 × 0.70 × 0.88 × 0.77
            = 341_510_400 تومان

بازه        = ۳۰۰٬۰۰۰٬۰۰۰ تا ۴۰۰٬۰۰۰٬۰۰۰ تومان
```

## سقف‌ها و محدودیت‌ها

| مورد | مقدار |
|---|---|
| حداکثر کاهش سال | ۵۰٪ |
| حداکثر کاهش کارکرد | ۳۰٪ |
| حداقل ضریب رنگ | ۰٫۸۲ (رنگ چند ناحیه) |
| حداقل ضریب شاسی | ۰٫۶۵ (آسیب شدید) |
| بدترین ترکیب ضرایب (بدون قیمت پایه) | `0.50 × 0.70 × 0.82 × 0.65 ≈ 0.186` |
| یعنی در بدترین حالت حدود **۱۸٫۶٪** قیمت پایه باقی می‌ماند | |

سال ساخت در UI باید بین **۱۳۸۰** و **`lastYear + 1`** باشد. کارکرد نمی‌تواند منفی باشد.

## ترتیب اعمال ضرایب

ضریب‌ها مستقل و ضرب‌شونده‌اند؛ ترتیب ضرب روی نتیجه اثر ندارد. جریان منطقی صفحه این است:

```
جستجوی خودرو
    → اصلاح قیمت پایه (همراه مکانیک)
    → سال ساخت
    → کارکرد
    → وضعیت رنگ
    → وضعیت شاسی
    → قیمت نهایی + بازه ۱۰۰ میلیونی
```
